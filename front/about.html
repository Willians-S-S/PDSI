Sobre o Projeto

Este sistema utiliza tecnologias de visão computacional e aprendizado de máquina para prever o peso de pequenos ruminantes. Ideal para fazendas que desejam otimizar a gestão do rebanho e melhorar a tomada de decisões.

Objetivos

  • Prever o peso dos animais com precisão;
  • Facilitar o gerenciamento de dados de fazendas;
  • Integrar informações de usuários, animais e histórico de peso.
